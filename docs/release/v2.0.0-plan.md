# v2.0.0 — release plan and record

The living record of the v2.0.0 release: the decisions, the measured state they rest on, and the
ordered steps. Update it **as part of the work** — a step done but not ticked here is
indistinguishable from one never taken. When the release ships, this file stays as its record.

## Decisions — owner, 2026-11-24 (answered over the question relay)

| # | question | decision |
|---|---|---|
| D1 | version of the next release | **v2.0.0** — a change of identity (orchestration → harness/fleet), and the retired `/set:*` commands are a breaking change for any consumer still calling them |
| D2 | timing | **release now, with the orchestration engine marked dormant**; the engine is removed in a later release (`retire-orchestration-engine`) |
| D3 | AI+ repos in the public docs | **list all 7 public AI+ repositories** of the `itlinekft` org (below) |

**D2 supersedes an ordering recorded on 2026-11-23.** The closure note of
`openspec/changes/archive/2026-11-23-docs-rewrite-release/proposal.md` says the doc set is
rewritten *after* `retire-orchestration-engine` lands. The owner chose to release first; the docs
are therefore rewritten now, around the harness, with the orchestration chapters kept as a record
and labelled dormant.
