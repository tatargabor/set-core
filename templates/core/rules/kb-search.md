# Search the project knowledge base before you claim or plan

`set-kb search "<topic words>"` ranks sections over every indexed markdown file
of this project. Reach for it at three moments:

1. **Before claiming there is no source, precedent or prior decision** — search
   first; the archive of past changes is indexed too.
2. **Before planning a change** — the topic may already be decided or measured.
3. **When a grep returns more files than you will read** — let the ranking work.

Zero hits describe the index, not the world: the page names the query and the
exclusions in force. `set-kb get <path>` prints a hit verbatim; `set-kb doctor`
explains a corpus that looks wrong; `set-kb sources` lists what the corpus
covers and what each layer is.
